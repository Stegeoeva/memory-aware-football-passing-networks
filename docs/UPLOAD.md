# Uploading the public research repository

Use **Football_Passing_Networks_PUBLIC.zip**, generated by `python scripts/package_repository.py`. Extract it into a dedicated folder outside any unrelated Git repository. Upload the extracted contents as source files, rather than attaching the ZIP as a repository data asset.

The public bundle includes code, English methods, four source-only notebooks, twelve aggregate figure pairs, the attribution logo and source-download manifests. It contains no event tables, actual pass sequences, trained xT grids, saved prediction matrices or notebook outputs. The earlier full local-delivery ZIP is superseded for public upload.

Create an empty GitHub repository, for example `memory-aware-football-passing-networks`, without generating a README/license remotely. Suggested description:

> Non-commercial EURO 2024 research on passing-network memory, held-out prediction and aggregate source-xG motif quality. Code and methods; data obtained directly from StatsBomb.

From the extracted public directory:

~~~shell
git init -b main
python -m unittest discover -s tests -v
python scripts/check_repository.py
git add .
git status --short
git commit -m "Publish code and aggregate passing-memory research"
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
git push -u origin main
~~~

Replace the remote URL. GitHub Desktop is an alternative. Review the staged list: detailed CSV/CSV.gz, serialized model parameters and executed notebook outputs do not belong in the public repo. The public checker compares tracked files with the allowlist when run in a standalone Git checkout.

Read [the publication policy](PUBLICATION_POLICY.md) before publishing. The MIT license covers only original code; StatsBomb terms apply to its data and derived analysis. Attribution/logo are retained. This packaging is not written permission or a legal guarantee for additional redistribution or commercial use.

After any local notebook execution, run `python scripts/strip_notebook_outputs.py` before committing. CI runs synthetic tests and public-file checks without downloading the dataset, retraining models or executing data-bearing notebooks.
