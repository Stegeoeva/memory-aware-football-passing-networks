The agreement restricts redistribution of data and commercial exploitation of the data or resulting analysis, while permitting public sharing of analysis/conclusions and requiring the StatsBomb logo. This repository presents non-commercial research.

The public package contains code, methodology, source-only notebooks and selected aggregate analytical figures. It excludes detailed data tables, actual event/sequence records, saved predictions and trained parameter files, including xT grids. Users restore inputs directly from the official upstream repository using the checksum-verified downloaders. Source manifests contain paths/hashes rather than event records.

The original logo is included at [assets/statsbomb-logo.png](assets/statsbomb-logo.png), with attribution in the public gallery and analysis figures. Retain this source attribution and logo when sharing the analysis.
